# CampusBite 🍔

**Good Food. Campus Vibes.**

A demo food-ordering website built for a college technical club project. Browse a canteen-style menu, search & filter by category, add items to a cart, and walk through a full (simulated) checkout flow — all in plain HTML, CSS and vanilla JavaScript.

## Live demo
Open `index.html` directly in any browser — no build step, no dependencies, no backend required.

## Features
- Responsive, animated UI with a custom "order ticket" hero
- 17 sample menu items across 6 categories (Pizza, Burgers, Meals, Snacks, Desserts, Drinks)
- Live search + category filtering
- Food detail view with quantity selector and demo reviews
- Fully working cart (add / update quantity / remove) persisted with `localStorage`
- Checkout form with field validation
- Order confirmation with a generated demo order number and prep-time estimate

## Tech stack
HTML5 · CSS3 (custom properties, Grid/Flexbox) · Vanilla JavaScript — no frameworks, no build tools.

## Project structure
```
campusbite/
├── index.html   # markup & page structure
├── style.css    # all styling, layout, animations, responsiveness
├── script.js    # menu data, cart logic, search/filter, checkout, confirmation
└── README.md
```

## Note
All food items, prices, ratings, reviews, and orders are fictional demo data created for this project. No real payments, deliveries, or businesses are involved.
